یادگیری Flexbox

با Flexbox می‌توانیم عناصر صفحه را به سادگی در یک ردیف یا ستون قرار دهیم و نحوه قرارگیری آن‌ها را کنترل کنیم.

fake image

display: flex

با این ویژگی یک عنصر به Flex Container تبدیل می‌شود.

justify-content

برای کنترل نحوه قرارگیری آیتم‌ها در محور اصلی استفاده می‌شود.

align-items

برای کنترل آیتم‌ها در محور مخالف محور اصلی استفاده می‌شود.
