# 📚 مطالب دوره و سوالات متداول

توی این مخزن، **کد نهایی تمام بخش‌ها و پروژه‌های دوره** قرار گرفته.

💡 پیشنهاد می‌کنم هر وقت جایی از کدت درست کار نکرد، اول کدت رو با **کد نهایی** مقایسه کن. این کار خیلی وقت‌ها سریع‌تر از هر چیزی کمکت می‌کنه مشکل رو پیدا کنی.

👇 **قبل از شروع دوره، حتماً سوالات متداول زیر رو یه نگاه بنداز.** 👇

## ❓ سوالات متداول

### 📥 سوال ۱: فایل‌ها رو چطوری دانلود کنم؟

**پاسخ:** اگه با GitHub زیاد آشنا نیستی و فقط می‌خوای کل کدهای پروژه رو دانلود کنی، روی دکمه سبز رنگ **"Code"** بزن و بعد گزینه **"Download ZIP"** رو انتخاب کن.

### 🆘 سوال ۲: گیر کردم! از کجا کمک بگیرم؟

**پاسخ:** اول از همه، یه بار خودت سعی کن مشکلت رو حل کنی. 😄

کدت رو با **کد نهایی** مقایسه کردی؟ شاید جواب درست جلوی چشمت باشه!

اگه بعد از بررسی و تلاش خودت هنوز نتونستی مشکلت رو حل کنی، از طریق [telegram](https://t.me/cyborg_x86) بهم پیام بده و حتماً لینک [codepen](https://codepen.io/pen/) که کدت داخلشه رو برام بفرست.

📌 اونجا کمکت می‌کنم.

**پاسخ:** من برای این دوره از [تنظیمات](vscode-setup.md) استفاده می‌کنم.
